# Сайт SmartC iCrossWalk

Статический **одностраничный** сайт (HTML + CSS + JS, без сборщиков и зависимостей),
сверстан по макету «SmartC бел» (desktop 1440px) с адаптивом под планшеты и телефоны.

Все разделы идут друг за другом на одной странице `index.html`. Меню вверху всегда видно
(закреплено при прокрутке): клик по пункту плавно прокручивает к разделу, текущий раздел
подсвечивается. На узких экранах (до 1180px) пункты меню — горизонтальная полоска с прокруткой вбок.

## Быстрый старт

Сайт не нужно собирать: просто скопируйте содержимое папки в корень сайта на сервере
(например, `/var/www/icrosswalk.ru/`). Главная страница — `index.html`.

Посмотреть локально:

```bash
cd smartc-site
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Структура

```
index.html            Весь сайт (одна страница), разделы по порядку:
                        #top          первый экран
                                      цели + карта регионов, «Непропуск пешехода»
                        #about        О нас
                        #icross       Система iCrossWalk
                        #examples     Примеры реализации
                        #spin         СПИН Периметр
                        #cooperation  Условия сотрудничества
                        #documents    Документация (письма и сертификаты открываются по клику)
                        #founder      Основатель
                        #request      Форма «Оставить заявку»
404.html              Страница «не найдено»
send.php              Обработчик формы заявки (PHP, отправка на почту)
assets/css/style.css  Все стили (переменные цветов — в начале файла)
assets/js/main.js     Меню (подсветка раздела, плавный переход), отправка формы, просмотр документов
assets/fonts/         Шрифт Manrope (variable, кириллица + латиница), подключён локально
assets/img/           Все изображения
files/                PDF-презентации (кнопки «Скачать презентацию»)
.htaccess             Настройки для Apache (кэш, gzip, 404) — для nginx см. ниже
robots.txt, sitemap.xml
```

На раздел можно дать прямую ссылку: например, `https://www.icrosswalk.ru/#documents`.
Каждый раздел в `index.html` отмечен комментарием `<!-- ===== Название ===== -->`.
У файлов стилей и скриптов в `index.html` стоит `?v=…` — после правок CSS/JS поменяйте
это число, чтобы у посетителей не остался старый вариант из кэша браузера.

## Форма заявки

Форма в конце страницы (`#request`, на неё ведут все кнопки «Оставить заявку»)
отправляется AJAX-запросом на `send.php`, который шлёт письмо на **info@icrosswalk.ru**.

- Адреса получателя/отправителя меняются в начале `send.php` (`$TO`, `$FROM`).
- Нужен PHP 7.4+ и рабочая функция `mail()` на сервере. Если почта через `mail()` не
  настроена — замените отправку на SMTP (PHPMailer) или на интеграцию с CRM/Telegram.
- Если бэкенд будет на другом языке — достаточно принять POST с полями
  `company`, `name`, `phone`, `email`, `page` и вернуть JSON `{"ok": true}`;
  адрес обработчика задаётся атрибутом `action` у формы в `index.html`.
- От спама: скрытое поле-ловушка `website` (боты его заполняют — такие заявки отбрасываются).

## nginx (пример)

```nginx
server {
    server_name icrosswalk.ru www.icrosswalk.ru;
    root /var/www/icrosswalk.ru;
    index index.html;
    charset utf-8;
    error_page 404 /404.html;

    location / { try_files $uri $uri/ =404; }

    location = /send.php {
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $document_root/send.php;
        fastcgi_pass unix:/run/php/php-fpm.sock;   # путь к сокету php-fpm на вашем сервере
    }

    location ~* \.(css|js|jpg|jpeg|png|webp|svg|woff2|pdf|ico)$ {
        expires 30d;
        add_header Cache-Control "public";
    }
    gzip on;
    gzip_types text/css application/javascript image/svg+xml application/json;
}
```

## Что проверить перед запуском

1. **Ссылка Telegram** у QR-кода в подвале ведёт на `https://t.me/smartcveshaet` —
   взята по подписи под QR (@SMARTCVESHAET). Сам QR стилизованный, автоматически не читается —
   отсканируйте телефоном и убедитесь, что адрес совпадает.
2. **«Мы в VK»** ведёт на `https://vk.com/club232152279` (сообщество со старого сайта).
3. **Презентации** в `files/` скопированы со старого сайта (`/upload/SmartC-icrosswalk2025.pdf`
   и `/upload/SmartC-SPIN2025.pdf`). Если со старых адресов есть внешние ссылки — сделайте
   редиректы `/upload/... → /files/...`.
4. **Домен** в `sitemap.xml`, `robots.txt` и тегах `canonical`/`og:url` — `https://www.icrosswalk.ru/`.
   Если сайт будет на другом адресе — замените поиском по проекту.
5. Под формой добавлена строка о согласии на обработку персональных данных (152-ФЗ).
   Если у компании есть страница политики конфиденциальности — добавьте на неё ссылку.

## Отличия от макета (сознательные)

- В макете каждый раздел был отдельной страницей — по просьбе заказчика всё собрано в один
  длинный лендинг с меню-якорями. Внешний вид каждого раздела — как в макете.
- Форма «Оставить заявку» перенесена в конец страницы (перед подвалом).
- Исправлены опечатки: «Распознование» → «Распознавание», «зарегестрировано» → «зарегистрировано»,
  в подвале «10,01» → «10.01».
- Карта регионов сделана HTML-вёрсткой (а не картинкой) — она чёткая на любом экране;
  на телефоне карта прокручивается горизонтально. Данные по регионам — в `index.html`
  (блок `ru-map`, у каждой плитки `--c` — колонка, `--r` — строка).
- Шапка закреплена при прокрутке. Значок логотипа в шапке появляется после первого экрана
  (в макете он стоит в первом экране над заголовком).
- Макет был только десктопным (1440px) — адаптивные версии (планшет/телефон) сделаны по его стилю.
